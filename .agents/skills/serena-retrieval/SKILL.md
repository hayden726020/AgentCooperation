# Serena 代码符号精准检索规范 (Serena Retrieval)

在代码库规模扩大后，模糊全文搜索和全盘遍历会导致严重的上下文污染与响应延迟。Serena 检索规范通过**聚焦符号定义、引用拓扑与调用链**，实现低上下文、高精准定位。

## 一、代码定位四步走

1. **定位符号定义 (Locate Definition)**：
   - 目标：快速找出函数名、类名或配置常量的唯一真实定义位置。
   - 方法：优先按 `def <func_name>`、`class <ClassName>` 针对特定模块进行定向检索，而不是全局模糊匹配字符串。

2. **追溯调用引用 (Trace References)**：
   - 目标：分析修改目标函数会影响哪些调用方。
   - 方法：检索该符号在 `orchestrator/`、`web/` 或 `integrations/` 中的导入（import）与调用点，列出直接受影响的文件。

3. **关联测试定位 (Find Tests)**：
   - 目标：在修改代码前找出直接覆盖该功能的测试文件。
   - 方法：在 `tests/` 目录下定位 `test_<module>.py`，或在测试中搜索被测试类或函数名。

4. **划定最小上下文边界 (Bound Context Window)**：
   - 将修改与理解范围严格限制在“定义文件 + 直接调用方 + 对应测试”三者构成的最小子集内，坚决不加载其他无关模块。

---

## 二、Windows 本地高效检索实用实践

在当前 Windows 环境下，使用内置工具或 Python 脚本实现符号级检索：
- **符号定义查找**：针对性使用包含 `def ` 或 `class ` 的正则过滤。
- **排除规则**：始终排除 `__pycache__`、`.venv`、`data/`、`.runtime/`、`.worktrees/`、`references/` 与 `dist/`。
- **只读前 50 行结果**：避免将大批量检索结果直接打在控制台导致上下文失控。
