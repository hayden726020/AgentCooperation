# AgentCooperation 优化项目 (Vibe Coding 效率提升)

> **项目定位**：在不推倒重来、不丢失已有成果的前提下，全面优化 AgentCooperation 的工程架构、AI 上下文工程与多 Agent 协作流。

---

## 1. 核心目标

1. **解决 AI 响应慢与遗忘**：通过将项目状态、架构决策与路线图文件化（外部化存储在 `.planning/` 与 `docs/`），避免依赖单次超长上下文。
2. **避免重复扫描全库**：建立按需代码检索与结构化索引地图，让任何新会话的 AI 能通过精准检索秒级定位，不反复加载无用上下文。
3. **任务原子化与边界清晰**：大型功能严格拆分为可独立执行、测试和提交的小任务，避免任务偏移和修改范围失控。
4. **测试先行的确定性闭环**：所有修改以可复现的自动化测试结果为依据，测试通过 + 独立只读复核通过才算真正交付。
5. **Windows 本地开发高可用**：针对 Windows 10/11 环境强化进程树管理、超时看门狗与文件安全。

---

## 2. 核心技术约束与守则

* **单任务单 Flash 引擎**：自动流水线每任务 GLM 或 DeepSeek 二选一，严格互斥；阶段五闭环支持 Gemini 研发 + GLM/DeepSeek 独立复核。
* **预算硬上限**：¥200/月严格守护，每次模型调用必须经过预扣（reserve）与实际结算（settle）。
* **测试与代码修改**：测试代码改动必须先跑离线回归；全量入口：`python -m pytest tests/ -q -p no:cacheprovider`。
* **敏感数据零泄漏**：凭据、密钥、数据库路径不得硬编码或输出到 AI 项目记忆中。
* **渐进式重构**：优先修复高风险债务，保持向后兼容，不搞一次性颠覆式重构。
